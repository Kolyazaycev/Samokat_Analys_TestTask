## Описание выполненной работы

### Задание 1. Отчет в Power BI
На основе предоставленных выгрузок построена модель данных и создан аналитический дашборд. 
* Рассчитаны ключевые метрики: общая выручка, количество заказов и средний чек.
* Подготовлены визуализации: распределение выручки по городам, динамика продаж по дням (позволяет отследить тренды и сезонность) и топ-10 товаров по объему выручки.
* На этапе загрузки данных в Power Query приведены корректные типы данных (в том числе форматы с запятыми) и обработаны пустые значения.

### Задание 2. Выгрузка пользователей (Excel)
Необходимо было выгрузить `user_id` пользователей, купивших от 2-х кормов для животных в период с 1 по 15 августа (за исключением конкретного товара).
* В Power BI настроены фильтры по дате (01.08–15.08) и категории товара. 
* Исключена позиция «Корм Kitekat для кошек, с кроликом в соусе, 85 г».
* С помощью агрегации данных отобраны пользователи с суммарным количеством товаров >= 2. Результат экспортирован в Excel.

### Задание 3. SQL-запрос
Написан SQL-запрос к виртуальной БД (структура соответствует модели из первого задания) для поиска топ-5 товаров.
* Запрос реализован с использованием CTE (`WITH`).
* Логика работы: сначала определяется дата первого заказа для каждого пользователя в Санкт-Петербурге, затем отбираются заказы, попавшие в период с 15 по 30 августа, после чего вычисляется частота встречаемости товаров и выводится топ-5 с сортировкой по убыванию.
